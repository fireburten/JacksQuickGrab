Desktop screenshot tool. Tech stack: Electron 41, plain HTML/CSS/JS renderers, no build step.

**Branding:** Product name "Jack's Picker" (formerly "Jack's Quick Grab"). Owned by Rind Works. App icon is `picker-icon.png` (1024×1024 dock); HUD/tray uses `picker-hud.png`.

**Architecture:**
- `main.js` — Electron main process (CJS); tray icon, global hotkeys (⌘⇧2 region, ⌘⇧1 full, ⌘⌥⇧W window, ⌘⌥⇧2 repeat-region; ⌘⇧3/4/5 are allowed, but macOS swallows them until its own Screenshots shortcuts are turned off in System Settings → Keyboard → Keyboard Shortcuts, so the hotkey dialog shows a Mac note + `open-keyboard-settings` button and highlights it when a field sees ⌘⇧ go down without the key arriving. macOS has no deep link to the Screenshots section: `x-apple.systempreferences:com.apple.preference.keyboard?Shortcuts` opens the Keyboard Shortcuts sheet on the last-used section, and the Keyboard extension only exposes the anchors shortcuts/functionkeys/services/inputSources/text/keyboard. So the dialog gives numbered steps), window lifecycle
- `preload.cjs` — IPC bridge (must be .cjs, not .js, to stay CommonJS)
- `src/hud.html` — Floating draggable toolbar; `-webkit-app-region: drag` on logo handle
- `src/capture.html` — Fullscreen region-selection overlay; canvas-based screenshot + drag selection
- `src/editor.html` — Canvas annotation editor; tools: arrow, text, box, highlight, blur, draw; copy/save/OCR actions
- `src/window-picker.html` — Window thumbnail picker
- Gallery also lists GIFs/recordings (`kind: 'gif'|'video'` from `galleryPayload`); they open in the editor's media viewer, not the canvas. `safeCapturePath(p, { allowMedia: true })` gates which IPC actions accept media
- Media editing: engine `src/media-editor.js` (`window.MediaEditor`: openSource/drawFrame/grabFrame/exportMedia with a `clips` array + `drawOverlay` hook for the stitch/annotation phases; audio slot marked in `muxerOptions()`), vendored `src/vendor/mp4-muxer.js` (5.2.2, MIT, deprecated upstream but pinned). UI: the media viewer is a plain player; its Edit opens the video in the MAIN editor ("video mode", `body.video-mode`): a frame canvas replaces `bgImage` so all annotation tools + blur work live, `originalDataURL` is a `video-frame:` marker so undo doesn't reload a static base, `currentPath=null` so nothing autosaves, image-only actions (`.image-only`) are hidden, and `#video-dock` under the canvas holds timeline/trim/crop/export. The previous screenshot is snapshotted and restored on exit. A session is a list of clips (`mediaEdit.clips`, each with its own trim and `offset` on a combined timeline; canvas = first clip's size, others letterboxed; crop/annotations in canvas px, annotation times on the combined timeline). Add via the dock's "+ Add clip" clip finder (IPC `media-list` = ALL media in the folder, `media-thumb` lazy per card; search/type/project/sort, hover preview, numbered multi-select) or gallery multi-select → "Combine into video". Crop is real: once applied the canvas IS the crop (`mediaViewRect`, `me.view` canvas) and annotations are stored crop-relative; entering crop mode shifts them back to frame coords (undo is blocked mid-crop; `snapshot()` carries `videoCrop`). Sessions auto-save to `.annotations/<video>.video.json` (IPC `video-session-load/save`, moved/removed with rename/delete) and restore on the next Edit of that video. Annotations outside their time are fully hidden, even when selected. Export uses the engine's `compose` mode (`renderFrame` per output frame) so the UI owns composition and the engine only encodes. Exports paint the canvas annotations per frame via `mediaOverlayPainter`. Annotations can carry `t0`/`t1` (source seconds; absent = whole video) set from the Inspector's "Show during" or the annotation lane under the timeline (one bar per annotation; `renderAnnLane` rebuilds only when its key changes); `annVisibleAt` gates render, hit-testing and export. `let mediaEdit` is declared with the top-level editor state because render()/updateInspector() read it during startup. `drawAnn(..., guides=false)` for anything exported. Edits always save as `<name>-edited.<ext>`. Tests: `./node_modules/.bin/electron scripts/test-media-editor.cjs` (offscreen window — Chromium defers media in hidden windows)
- Project folders: a project can be linked to a real folder (main registry `settings.projectFolders[projectId] = {path, bookmark, exported, imported}`; MAS uses security-scoped bookmarks + `files.bookmarks.app-scope`). Assigning captures copies them in (screenshots as the annotated `.flat.png`, refreshed on edit; never overwrites a file we didn't create). Folder files are listed in the project as `external` items (read-only: `safeCapturePath(..., {allowLinked:true})` only for read/preview/drag/edit-a-copy; opening a folder image imports a capture copy). `fs.watch` refreshes the gallery. Test the real handlers with `scratchpad`-style Node harness faking `electron` + temp HOME.
- Recording audio: HUD toggles 🔊 (system audio → `getDisplayMedia({audio:true})`, main's display-media handler answers `audio: 'loopback'`, macOS 13+) and 🎙 (mic → `mic-access` IPC / `askForMediaAccess`, then `getUserMedia`), mixed via WebAudio into one AAC track (`video/mp4;codecs=avc1,mp4a.40.2`). Prefs live in the settings store (`recording.systemAudio/mic`; the old HUD localStorage `jqg-rec-audio` is migrated once, then removed). NSMicrophoneUsageDescription + MAS `device.audio-input` entitlement. In the editor each clip's audio is decoded in the background (`MediaEditor.decodeAudio`), previewed with WebAudio (mute button), and exported via `compose.audio` segments.
- Streamed captures (Record / GIF / Scroll) run in `src/hud.html` off one `getDisplayMedia` stream cropped to the overlay region; `main.js` `streamMode` routes the overlay result. GIF uses vendored `src/vendor/gifenc.js` (MIT, wrapped as `window.gifenc`); Scroll uses `src/scroll-stitch.js` (`ScrollStitcher` engine is down-only; `DirectionalScrollStitcher` handles up/left/right by flipping/transposing frames; the HUD runs all four until one moves, then locks; tests: `node scripts/test-scroll-stitch.cjs`)
- Settings + theming: main owns the store (`settings.json`, `cleanPrefs()` validates `appearance{theme,accent,highContrast,uiScale,hudScale,thumbSize}`, `editor{color,stroke,textSize(0=auto)}`, `recording{systemAudio,mic,gifFps,gifWidth}`, `autoCopyAfterCapture`; launch at login only when packaged). Renderers call `settingsGet/settingsSet`; `updateSettings()` merges, saves, applies (`nativeTheme.themeSource`, per-window `setZoomFactor` — file:// pages zoom independently — `sizeHUD()`, window `backgroundColor` via `windowBackground()`) and broadcasts `settings-changed` to every window. `src/theme.css` = colour tokens (`--bg-*`, `--fg*`, `--line*`, `--ink`, `--accent`/`--accent-rgb`; dark default, `[data-theme="light"]`, `[data-contrast="high"]`); `src/theme.js` (`JPTheme.apply`, cached in localStorage `jqg-appearance` to avoid a flash, fires `jp-appearance`) — every page loads both. Canvas drawing reads `--accent-rgb` (editor `accentRGBA()`, capture `PURPLE`) and re-renders on `jp-appearance`. UI: `src/settings-panel.js/.css` (`window.JPSettings.open(section)`), opened by ⌘, (editor or HUD; the HUD sends `settings-open`) / Tools → Settings… / tray → Settings…, all ending in main's `openSettings()` → `open-settings` IPC. Gotcha: Electron calls a menu item's `click(menuItem, window, event)`, so never pass a function with optional params directly (`click: openSettings` sent the MenuItem as the section); `webContents.send` doesn't throw on unserializable args, it only logs "Failed to serialize arguments" and drops the message. Gallery sizes via `body[data-thumbs]`. Captures folder can be changed (`captures-folder-choose/apply`, MAS bookmark `saveDirBookmark`); existing captures + sidecars + video sessions move with it (name clashes skipped), and the editor remaps order/pins/projects via `window.onCapturesFolderChanged`. Tests: `./node_modules/.bin/electron scripts/test-theme.cjs` (renders every page per theme).
- Release hardening (2026-09-27):
  - `scripts/after-pack.cjs` (electron-builder `afterPack`, `@electron/fuses` 1.8, the CJS line) turns off RunAsNode, NODE_OPTIONS and `--inspect`, and turns on asar integrity plus OnlyLoadAppFromAsar.
  - `main.js` makes packaged builds `process.exit(1)` on `--remote-debugging-port`/`--remote-debugging-pipe`.
  - So the **packaged app can no longer be driven with CDP or `--inspect`**. Test with the harnesses or `npm start`.
  - Main-process errors go to `logError()` → `~/Library/Logs/Jack's Picker/main.log`, via `reportProblem` (a friendly dialog at most every 30 s), the `render-process-gone` reload (max 3 a minute; the overlay/picker are cancelled instead) and page `console-message` errors. Settings → Storage → Diagnostic log opens it.
  - `gallery-delete` is Trash-only: on failure it returns `{success:false, reason:'trash'}` and never unlinks.
  - The editor's runtime badge shows only in dev; the Settings footer shows the version and build date.
- Release tooling:
  - `npm run check:release` (`scripts/check-release.cjs`) also runs as `prebuild:mas` / `prebuild:mas-dev`.
  - `build:mas` sets `buildVersion` to `git rev-list --count HEAD`, so uploads must be committed.
  - `npm test` runs every `scripts/test-*.cjs` suite (the list is in package.json and the README). test-main-process is Node with a fake electron (`MAIN_JS=` tests another copy); most others are offscreen Electron.
- Gotcha: the repo is in `~/Documents`, which is **iCloud Drive**. It tags `.app` bundle folders with `com.apple.FinderInfo` (even inside `*.nosync`), so `codesign` fails with "resource fork, Finder information, or similar detritus not allowed".
  - That's why after-pack re-signs only the Electron Framework binary, ad hoc.
  - Real signing must run with the repo outside iCloud; check-release flags it.
- Business features (2026-09-28/29). Main-process modules are in `lib/`, page scripts in `src/`.
  - **Annotation tools** (editor.html): new types `step` (numbered badge; auto-increments; Renumber in the Inspector), `ellipse`, `line`, `spotlight` (all spotlights are dimmed together by `drawSpotlights`) and `blur` with `mode:'pixelate'` (explicit block averaging). Variants share a rail button (`TOOL_VARIANTS`); the props bar shows variant chips. Every draw goes through `drawAnnList()`. `flatDataURL()` is now the clean composite, so copies have no selection handles.
  - **Brand** (Settings → Brand, `settings.brand`): company name, logo (`BRAND_LOGO_PATH` = userData/brand/logo.png, IPC `brand-logo-*`), a watermark as an `image` or `stamp{style:'watermark'}` annotation, `stamp` annotations (Tools → Add Stamp…), a palette that replaces the toolbar swatches. New captures get the defaults in `applyBrandDefaults()`. `loadImageWithAnns` resolves after the document is set up.
  - **Search index**: `lib/search-index.cjs` keeps OCR text per capture in userData/search-index.json. The OCR helper reads a temp copy. It's scheduled on gallery-list and annotation saves. `gallery-search` searches ALL captures; `settings.searchText`.
  - **Redaction**: `src/redact-detect.js` (UMD) detectors. Smart Redact uses word boxes from `ocrTableImage` (obsId = line). `checkBeforeSharing(verb)` gates Copy, Share, Save and Send to…; `settings.checkSensitive` pauses auto-copy.
  - **Copy Text from Screen**: hotkey kind `text` (⌘⌥⇧T) → region overlay with `textCaptureMode` → OCR → clipboard → `hud-flash`.
  - **Managed settings**: `managedPolicy()` reads macOS user defaults as strings, and `applyPolicy()` overrides settings. `settings.managed` locks UI. Keys are in the README and `docs/managed-settings-example.mobileconfig`. `sharingAllowed()` uses DisableSharing. `settings.thumbnailUnavailable` forces the editor when a stamp, watermark or check is on.
  - **Agent-built pieces** (each with a test):
    - Create Guide: `lib/guide.cjs`, `src/guide-dialog.*`; `guideBrand()` uses Brand.
    - Camera bubble: `src/webcam.js`, HUD 📷, `recording.camera*`, HUD_WIDTH 557.
    - Thumbnail and Pin: `lib/quick-access.cjs`, `src/thumbnail.*`, `src/pin.*`, `settings.afterCapture`.
    - Send to…: `lib/sharing/*`, `src/sharing.js`, `src/settings-sharing.js`; credentials kept with safeStorage; `network.client` entitlement.
  - **Accessibility**: `scripts/test-accessibility.cjs` audits names, dialogs and keyboard use. `enhanceDialog()` makes `.choice-backdrop` dialogs real dialogs (focus in and out, Esc). theme.css has a global `:focus-visible` ring and reduced motion.
  - **Translations** (en, de, es, fr, ja; machine-drafted, need native review): `src/i18n.js` (UMD `JPi18n`); English text is the key, `tr(text, {vars})`. Tables in `src/locales/*.js` are GENERATED from `scripts/locales-source.py` (run `python3 scripts/locales-source.py`; it has a coding line because Python 3.9's tokenizer chokes on long UTF-8 lines). Pages translate markup at load plus a MutationObserver for later text; `[data-no-i18n]` protects user content. `appearance.language` ('system' or a code) is cached in localStorage `jqg-language`; theme.js reloads a page when it changes. main.js uses `tr()` for menus and dialogs. `electronLanguages` limits the bundle's .lproj folders, and after-pack writes translated `InfoPlist.strings` for the permission prompts. Test fakes of electron's `app` need `getLocale`. `scripts/test-i18n.cjs` renders windows in German; `scripts/i18n-strings.cjs` lists the English strings.
  - **Test gotchas**: page code must ask through `window.confirm`/`alert` (tests stub them); a real native dialog from an offscreen test window waits for a click and hangs the suite. Electron ignores SIGALRM, so `perl -e 'alarm…'` doesn't stop a hung Electron test; poll the pid and `kill` it instead.
  - **Merging agent worktrees**: they live in `.claude/worktrees/` (git-ignored). Merge each file with `git merge-file ours base(HEAD) theirs`.
- `scripts/ocr*.swift` — Vision-framework OCR sources, precompiled by `scripts/build-ocr.sh` into universal `bin/ocr` + `bin/ocr-table` (gitignored, asarUnpacked; runs automatically before `npm start`/builds). Never run them via `/usr/bin/swift` — end users lack Xcode tools and the App Store forbids runtime code.
- `scripts/ocr-table.ps1` — Windows.Media.Ocr helper
- `build/` — Mac App Store entitlements + padded macOS icon; `store/` — App Store Connect copy and privacy policy

**Capture flow:** hide HUD → 120ms delay → desktopCapturer screenshot → show overlay with screenshot as background → user drags region → crop in renderer → open editor.

**Captures save to:** `~/Documents/Jack's Picker/` (direct builds) or `~/Pictures/Jack's Picker/` (Mac App Store builds, `process.mas` — sandbox only has the Pictures entitlement) (legacy `~/Documents/Jack's Quick Grab/` is auto-renamed on first launch via `migrateLegacySaveDir`, only while the default folder is in use). Users can pick another folder in Settings → Storage (`settings.saveDir`, applied by `restoreCapturesFolder()` at startup; `SAVE_DIR`/`ANNOTATION_DIR` are `let` and change via `setSaveDir`). Annotations live in `.annotations/*.json` + `.flat.png` sidecars.

**How to apply:** When adding features, keep renderers as plain HTML (no bundler). Use IPC for all main↔renderer communication. Internal identifiers (`jqg-*` localStorage keys, `jqg-*` temp prefixes, IPC channel names) are intentionally kept unchanged across the rebrand to preserve user state — only user-visible strings, the app icon, and packaging identity moved to "Jack's Picker" / "com.rindworks.jackspicker".
